## On the table

- **Orca** — open-source IDE built for running coding agents side by side in isolated git worktrees — Claude Code, Codex, OpenCode — Ghostty-inspired terminal, embedded browser with design mode, mobile companion — [onorca.dev](https://www.onorca.dev/)
- **Herdr** — background runtime that keeps coding agents alive when your machine closes or disconnects — persistent terminals across workspaces, working/blocked/idle status tracking, drops into 19+ agent CLIs with no modification — [herdr.dev](https://herdr.dev/)
- **beads** — the ticket system for the agents we left open at AA11, except someone already built it — a dependency-aware issue graph in a Dolt-backed SQL database, where `bd ready` returns only the claimable frontier (open beads with no open blockers) so an agent never picks up step three before step one lands. Hash IDs like `bd-a1b2` so parallel agents and branches don't collide on merge, `discovered-from` edges so work found mid-task gets recorded instead of dropped, and semantic compaction that summarises old closed beads to save context. Wires into Claude Code as a SessionStart hook running `bd prime` rather than MCP — the docs claim ~1-2k tokens against MCP's 10-50k. Is the dependency graph the thing markdown plans were always missing, or a project-management layer we'll resent maintaining? — [beads.gascity.com — how it works](https://beads.gascity.com/core-concepts/) — [github.com/gastownhall/beads](https://github.com/gastownhall/beads)
- **`/powerup`** — Claude Code's built-in interactive tutorial, shipped back in v2.1.90 and quietly sitting there ever since — ten animated lessons on what power users actually do: @-mentions, plan mode, `/rewind`, background tasks, MCP, CLAUDE.md, skills and hooks, subagents, `/remote-control`, `/model` and `/effort`. Five minutes a lesson, progress saved as you go. Show of hands — who's run it, and what's in there that the rest of us are still doing the hard way? — [docs — commands](https://code.claude.com/docs/en/commands) — [v2.1.90 release](https://github.com/anthropics/claude-code/releases/tag/v2.1.90)

## Claude 1337 micro

- `Ctrl+S`<br />
  Stash the prompt — press again on an empty prompt to get it back whole, cursor position and pasted images included
- `Esc` `Esc`<br />
  Empty input opens the rewind menu — with text, clears the draft and files it in history so `Up` recalls it
- `Ctrl+L` ×2<br />
  `/clear` and a fresh conversation, within two seconds — fullscreen rendering only; a single press just redraws
- `Ctrl+O`<br />
  Transcript viewer — then `[` spills the conversation into native scrollback for `Cmd+F` and tmux copy mode, `v` opens it in `$EDITOR`, `{` and `}` jump prompt to prompt
- `Ctrl+G`<br />
  Open the prompt in `$EDITOR` — `Ctrl+X` `Ctrl+E` is the readline-native binding
- `Ctrl+R`<br />
  Reverse-search command history
- `Ctrl+X` `Ctrl+K` ×2<br />
  Stop every background subagent in the session, within three seconds
- `Ctrl+B`<br />
  Background a running task — tmux users press twice
- `Ctrl+K` — `Ctrl+U` — `Ctrl+W`<br />
  Kill to end of line — to line start — previous word
- `Ctrl+Y`<br />
  Paste the last kill — `Alt+Y` then cycles the paste history
- `Ctrl+_`<br />
  Undo the last input edit
- `Alt+P`<br />
  Switch model without eating your prompt
- `Alt+T`<br />
  Toggle extended thinking — no effect on Fable 5, which always thinks
- `Alt+O`<br />
  Toggle fast mode
- `Shift+Tab`<br />
  Cycle permission modes — Manual, acceptEdits, plan, then bypassPermissions or auto where available
- `Ctrl+T`<br />
  Show or hide the task checklist
- `Ctrl+Z`<br />
  Suspend to your shell — `fg` to come back
- `Ctrl+D` ×2<br />
  Exit, within 800ms — with text in the prompt it deletes forward instead
- `?`<br />
  On an empty input, print the shortcut panel for your terminal
- `!`<br />
  Shell mode — run a command and drop its output into the session
- `\` + `Enter` — `Ctrl+J`<br />
  Newline in any terminal — `Shift+Enter` works natively in iTerm2, Ghostty, Kitty, WezTerm, Warp and Windows Terminal
