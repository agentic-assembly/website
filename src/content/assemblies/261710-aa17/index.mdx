### New Claude Code commands & features
- **Fork subagents everywhere — `CLAUDE_CODE_AUTO_MODE_MODEL`** (v2.1.302, 2026-10-16) — `subagent_type: "fork"` is now on by default in `claude -p`, the Agent SDK, the desktop app and VS Code, as it already was in the terminal (`CLAUDE_CODE_FORK_SUBAGENT=0` turns it off); desktop and VS Code always run the main conversation's subagents in the background; pick the auto mode classifier's model; an "Idle compaction" row in `/config`; `claude -p` on third-party providers now starts in `default` permission mode, not auto — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)
- **Vim `%` — `fable` falls back** (v2.1.301, 2026-10-15) — jump to the matching bracket, alone or with d/c/y; the `fable` and `best` aliases retry once on the previous Fable model if the newest is unavailable; switching to a smaller-context model now has the previous model summarise the conversation first; auto mode classifier verdicts land in OTel `tool_decision` events; LaTeX math in VS Code — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)
- **`/advisor` on AWS — mods get `virtualText`** (v2.1.300, 2026-10-14) — the advisor tool comes to Claude Platform on AWS (`advisorModel`, `--advisor`); mods can draw text in the prompt box that never enters the draft, show any agent's transcript with `$.ui.view({ agentId })`, and rewrite a workflow agent's prompt and model in `agent.spawn`; large API requests are gzipped; `claude remote-control` drops `--sandbox` in favour of `sandbox.enabled`; Claude in Slack works in Slack Connect channels — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)
- **Idle compaction — `/effort` and `/fast` in agent view** (v2.1.299, 2026-10-14) — a 200K+ token terminal session idle for ~54 minutes is compacted before its one-hour prompt cache expires, so coming back reprocesses a summary rather than the whole history (`"idleCompaction": false` to opt out); `CLAUDE_CODE_DISABLE_FILE_MENTIONS` sends `@` paths instead of contents; `/usage` warns about max effort, workflows and large tool results; `claude plugin eval --disallow-tools`; MCP allow rules now match only the exact named server — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)
- **Subagent `autoCompactWindow` — Read `allow_large`** (v2.1.296, 2026-10-09) — subagents can compact earlier than the main conversation; the Read tool can take a big text file in one call; `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` runs every workflow agent on one model; Sonnet 5.5 cache reads drop to $0.10; the MCP description cap doubles to 4,096 chars; Claude Tag can edit workspace and channel memory files — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.296)
- **Fail-closed hooks — terminal status via OSC 7501** (v2.1.295, 2026-10-08) — `onFailure: "block"` on command and HTTP hooks means a hook that can't start, times out or crashes blocks the action instead of waving it through; terminals that speak Program Status Protocol can show working, waiting or done; mods get native notifications with `$.ui.notify`; `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` caps unattended 429/529 waits — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)
- **Haiku 5.5 by default** (v2.1.293, 2026-10-07) — `claude-haiku-5-5` becomes the default Haiku on the Anthropic API (1M context, $0.10/$0.50, $0.50/$2.50 over 100K); `agentType` in the `subagentStatusLine` payload; mods can register tools that skip tool search with `isDeferred: false` — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.293)
- **Per-subagent `effort` — `claude plugin install --marketplace`** (v2.1.292, 2026-10-06) — the Agent tool takes an `effort` parameter so Claude runs a sub-agent at the level you ask for; install a plugin and its marketplace in one command; mods can add autocomplete rows (`prompt.autocomplete`) and cache `$.model.complete` calls — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.292)
- **`/claude-api managed-agents-onboard` — attach by name** (v2.1.290, 2026-10-05) — turn a page describing a Managed Agents pattern, or a Console quickstart like `deep-researcher`, into `ant apply` files; `claude attach` and `claude logs` accept part of a session name; mod `tool.check` hooks see `agentId` and the org's approval `ceiling` — [release](https://github.com/anthropics/claude-code/releases/tag/v2.1.290)
